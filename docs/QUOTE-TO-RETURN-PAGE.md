# QuoteToReturn public page contract

The canonical public page is `https://products.holic.work/quote-to-return/`.
It publishes the existing product concept and interactive demo without claiming
that the hosted software is ready.

## Public promise

QuoteToReturn is planned rental management software for small event-rental
teams. The page may describe inventory, availability, quotes, deposits,
reservations, pickup, delivery, return, damage notes, documents, and optional
AI-assisted customization.

## Release status

- The hosted product is not available for purchase or production use.
- The public demo uses fictional data, has no persistence, and makes no real
  changes.
- The planned price is USD 39 per month. It is not a live offer.
- The page has no Paddle or Waffo checkout until a usable hosted product exists.
- The public page is indexable and links to the site-wide Terms, Privacy Policy,
  support email, and howork products homepage.

## Copy boundary

Customer copy describes jobs and visible behavior. It does not use internal
architecture or validation terms such as kernel, code forks, bounded drafts,
raw SQL, Sandbox billing validation, or runtime.
