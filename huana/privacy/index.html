花哪隐私政策

最后更新：2026-08-20

本隐私政策适用于 iPhone 与 Android App「花哪」。花哪不包含广告、跨 App 跟踪或第三方行为分析工具。

账本数据保存在本机

你的原始输入、消费记录、标签、模式和统计所需数据保存在当前设备的加密 SQLite 数据库中。花哪没有云端账本、账号同步或自动备份，不会把完整账本上传给开发者或 AI 服务。

设备端语音识别

启用语音输入后，花哪使用麦克风采集当前说话内容，并在设备端完成识别。App 不生成录音文件，也不把音频上传到开发者或第三方服务器。首次使用需要下载语音模型文件。

自备密钥（BYOK）AI 解析

你可以自行填写 OpenAI 兼容 Endpoint、API Key 和模型名称。提交一条记录时，花哪会把这次原始输入、时间信息和完成标签归一所需的最少标签候选直接发送到你选择的 AI 服务；不会发送完整账本。该服务如何处理请求，受你选择的服务商隐私政策约束。

API Key 只保存在系统安全存储中，不写入账本、导出文件、日志或开发者服务器。Root 或越狱设备仍可能暴露本地密钥。

托管 AI 内测

受邀用户可以显式激活限期托管 AI 内测。激活会生成一个与姓名无关的安装标识，并把短期访问凭证保存在系统安全存储中。解析时，单次原始输入和最少上下文会经过 bookkeeping.holic.work 发送到固定 AI 提供商。

托管服务不保存原始输入、金额、商户、标签或完整模型输出。它会保存匿名主体、邀请码摘要、资格和额度、请求标识与状态、模型和主机、耗时、Token 用量，以及用户主动选择的最新付费意愿，用于防止重复请求、执行限额、运营内测和排查错误。它不会建立云端账本。

Excel 导出与系统分享

Excel 文件在设备上生成。只有当你主动使用系统分享面板时，文件才会交给你选择的其他 App、联系人或存储位置；这些接收方如何处理文件受其自身政策约束。

日志与支持邮件

运行日志不记录 API Key、原始输入、金额、商户、标签或完整 AI 输出。若你通过邮件联系支持，开发者会使用邮箱地址和邮件内容回复问题；请不要发送 API Key、邀请码、访问凭证或不必要的账本内容。

删除与选择

你可以在 App 内撤销账单、清空 AI 配置或退出托管 AI 内测。卸载 App 会移除设备上的本地数据。若要查询或删除与托管内测有关的匿名服务端数据，请使用下方邮箱联系，并提供 App 内可见的必要诊断标识；不要提供密钥或账本。

儿童隐私与政策更新

花哪不是面向儿童设计的服务，也不会故意收集儿童个人信息。若数据处理方式发生变化，本页面会更新日期和内容。
